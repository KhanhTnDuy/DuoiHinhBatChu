## Cách tạo ảnh nhanh (chọn 1 cách, giữ style đồng nhất)

1. **AI sinh ảnh** — dùng 1 prompt gốc cố định, chỉ thay phần mô tả:
   `flat vector illustration, minimal, thick outline, solid colors, plain white background, centered, no text — <mô tả trong cột draw>`
   Ghép 2–3 hình bằng cách yêu cầu "two objects side by side with a plus sign between them".
2. **PowerPoint / Canva** — mỗi câu 1 slide, chèn icon từ Flaticon/Icons8, thêm dấu `+` `−` `→`, export slide ra PNG.
3. **OpenMoji / Twemoji** — tải PNG emoji tương ứng rồi ghép.

## Kiểm tra trước khi đưa vào game

- [ ] Đủ 50 file `p001.png` … `p050.png` trong `Assets/Puzzles/`
- [ ] Mọi ảnh cùng tỉ lệ khung (16:9) để hiển thị full màn hình không méo
- [ ] Dung lượng mỗi ảnh < 250 KB
- [ ] Trong Visual Studio: chọn tất cả ảnh → Properties → Build Action = **Content**, Copy to Output Directory = **Copy if newer**
